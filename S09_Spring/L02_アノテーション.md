# アノテーション

- クラス、メソッド、フィールドなどに付与して、付加情報を与える仕組み
- Spring では DI や AOP などのために使用する

## アノテーションによる DI の例 (依存性注入)

- Repository クラス

```java: SampleRepository.java
package com.example;

import org.springframework.stereotype.Repository;

@Repository // リポジトリクラスであることを示すアノテーション
public class SampleRepository {
 public String getName() {
  return "test";
 }
}

```

- Service クラス

```java: SampleService.java
package com.example;

import org.springframework.stereotype.Service;

@Service // サービスクラスであることを示すアノテーション
public class SampleService {
 // フィールド定義
 private final SampleRepository sampleRepository;

 // コンストラクタで Repository を DI
 public SampleService(SampleRepository sampleRepository) {
  this.sampleRepository = sampleRepository;
 }
 
 // リポジトリのメソッドを呼び出す
 public String getName() {
  return sampleRepository.getName();
 }
}
```

- Spring Boot アプリケーションのエントリーポイント

```java: Spring1Application.java
package com.example;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class Spring1Application {

 // Spring Boot アプリケーションのエントリーポイント
 public static void main(String[] args) {
  
 // Service を DI
 SampleService sampleService
    = SpringApplication.run(Spring1Application.class, args)
        .getBean(SampleService.class);

 System.out.print(sampleService.getName());
 }
}
```
