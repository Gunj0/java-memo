# Java とは

- [Java](https://www.java.com/ja/)
- 1995 年にサン・マイクロシステムズが開発したプログラミング言語
  - 現在は Oracle が管理
- Java 仮想マシン(JVM)上で動作するため、プラットフォームに依存せずに動作する
  - Write Once, Run Anywhere: 一度書けば、どこでも動く
- オブジェクト指向をサポート

## 主な用途

- 業務システム
  - 銀行 ATM、大規模企業向け(エンタープライズ)システム
- Web アプリ
  - 大規模 EC サイト 等のバックエンド
- スマホ、ゲーム
  - Android アプリ、マインクラフト
- 組み込みシステム
  - 家電製品や車載システムなどの組み込み機器で動作するアプリケーション

## Java SE とは

- Java SE: Java Platform, Standard Edition
  - https://www.oracle.com/jp/java/technologies/java-se-glance.html
- Java の言語、JVM、API 等の仕様
- この仕様に基づいて、各ベンダーが JDK を提供している
