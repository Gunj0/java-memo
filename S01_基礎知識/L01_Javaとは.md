# Java とは

- [公式サイト](https://www.java.com/ja/)

- 1995年にサン・マイクロシステムズによって開発されたプログラミング言語
  - 現在はオラクル社が管理している。
- Java仮想マシン(JVM)上で動作するため、プラットフォームに依存せずに動作する
  - Write Once, Run Anywhere
- オブジェクト指向プログラミングをサポートしている。

## 用途

- エンタープライズ向けアプリケーション
  - 銀行・大規模企業向けシステム
- スマホ
  - Androidアプリケーション
- Webアプリケーション
  - サーバーサイドで動作するWebアプリケーション
- 組み込みシステム
  - 家電製品や車載システムなどの組み込み機器で動作するアプリケーション
